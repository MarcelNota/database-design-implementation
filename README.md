# The Brainery Database

A relational database designed and implemented for **The Brainery**, based on defined business rules and data requirements. The project focuses on applying relational database design principles to structure data efficiently, maintain data integrity, and support meaningful SQL queries.

## Overview

The project covers the complete database design process, from conceptual modelling to the implementation of a relational schema in MySQL.

It was designed around business requirements and translated into a structured database model using entities, attributes, relationships, constraints, and relational tables.

## Key Features

* Designed a relational database based on business rules and data requirements
* Modelled entities, attributes, and relationships using **Entity-Relationship (ER) diagrams**
* Defined **primary keys, foreign keys, cardinalities, and data integrity constraints**
* Created and implemented the relational database schema using **MySQL**
* Developed SQL queries for **data retrieval, filtering, grouping, and analysis**
* Applied normalization and relational database design principles to reduce redundancy and improve data consistency

## Database Design

The project follows a structured database design process:

**Business Requirements → ER Model → Relational Schema → MySQL Implementation → SQL Queries**

The database model identifies the main entities and their relationships while enforcing referential integrity through primary and foreign keys.
